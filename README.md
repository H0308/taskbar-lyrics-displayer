## 项目核心功能

- **任务栏内嵌歌词**：窗口作为任务栏（Shell_TrayWnd）的子窗口，外观贴近 Windows 11 原生媒体卡片——左侧圆角封面 + 歌名/歌手，右侧当前行歌词（超长自动滚动），支持 QQ 音乐、网易云音乐、汽水音乐和 Spotify。QQ 音乐、网易云音乐和 Spotify 加载歌词时显示「歌名 - 歌手」；歌词提前就绪时保留前奏信息至首句开始，歌词较晚到达时滚动切入当前进度对应的歌词行
- **四边任务栏与竖向歌词**：Windows 11 26H2 支持任务栏位于上、下、左、右四个位置
- **三种任务栏展示模式**：支持「内嵌」「沉浸」和「Dock 模式」。内嵌模式固定显示在主显示器；沉浸模式覆盖所选显示器的横向任务栏并居中显示歌词，可选择单台或全部显示器（全部时仅覆盖横向任务栏），提供上一首、播放/暂停、下一首、播放模式（受支持播放器）、音量、返回内嵌、时间与日期和完整托盘菜单，鼠标停在播放控件以外的区域时会淡出并让出任务栏，离开任务栏后自动淡入恢复；Dock 模式可显示在指定或全部显示器的顶部/底部，通过 Windows AppBar 为各目标显示器的桌面工作区预留空间，右侧显示频谱及资源监视；两种展开模式的遮罩不透明度（或模糊程度）可分别调节
- **资源监视**：Dock 自带资源区，横向内嵌模式可在设置中单独开启，沉浸模式不显示；固定显示 CPU 和内存，网络下行、网络上行、GPU 使用率和 CPU 频率可独立开关，关闭后由后续指标补位，没有后续指标时释放对应宽度，超过一页可用滚轮翻看；资源监视字体遵循通用字体的常规、加粗和斜体设置
- **多格式歌词与逐字高亮**：支持逐字时间轴歌词；逐字歌词按像素进度平滑填充并滚动，支持底深顶浅的已播放色连续渐变，LRC 保持整行高亮；当前歌曲没有可用翻译或罗马音时，可选双行歌词，同时显示当前行与下一行预览
- **歌词特效**：在「设置 → 歌词 → 歌词特效」独立开关星尘跟唱、跟唱流光、笔触下划线、字间涟漪、逐字浮波、歌词彩蛋，支持组合使用并保存选择，默认关闭，每项提供示意图。这六项需要逐字时间轴，其中星尘跟唱仅在单行模式显示：开启后歌词适当下沉，五角星在文字上方跟随逐字进度移动、跳动并缓慢旋转（每圈 3 秒），并带有向后散开并逐渐缩小、淡出的流星粒子拖尾，与文字保持间隙；竖排时星星沿字列右侧跟随，双行模式下暂停并保留开关偏好。逐字浮波支持横向单行和双行逐字歌词（竖向任务栏和小任务栏下停用），使整行长波轻柔起伏、当前唱词随逐字进度下沉后缓慢浮起，并与星尘跟唱互斥。歌词彩蛋仅在横向逐字歌词下生效（小任务栏和极简模式下停用），当唱词命中特定意象关键词时，在背景区域展示专属氛围动画。星尘跟唱还与辅助歌词互斥：开启星尘跟唱会自动关闭翻译/罗马音，重新开启辅助歌词会自动关闭星尘跟唱，辅助歌词的类型选择仍然保留。特效跟随横向、竖排中文和旋转英文的实际文字位置、缩放与裁剪，可与描边和光晕叠加；双行模式下其余特效仅作用于当前演唱行及其离场阶段，不作用于下一行预览、翻译或罗马音。文字定位、星形、字形位移和流光字形遮罩按布局或绘制资源缓存，转场保留合成器动画。暂停后短尾迹逐渐消散，拖动进度和切歌时重新同步；极简模式或关闭 Windows 系统动画时不显示
- **翻译与罗马音**：可显示部分外文歌曲的翻译或罗马音，并可从设置窗口启用、关闭及切换显示类型
- **QQ 音乐本地歌词**：在设置中选择 QQ 音乐本地歌词目录后，程序递归索引本地 QRC 缓存；手动保存的歌词优先，默认按本地→在线获取，本地未命中自动回退在线；托盘菜单可在本地版与在线版之间切换，并可按歌曲持久化选择
- **多播放器自动识别**：支持 QQ 音乐、网易云音乐、汽水音乐和 Spotify；多个播放器同时运行时，根据 Windows 当前媒体会话及播放状态自动选择正在播放的来源；切换平台时同步切换歌曲、歌词和控制目标
- **每日一言与空闲入口**：未检测到音乐播放器会话时可保留任务栏入口，显示来自一言、今日诗词或网易云热评的每日一言；支持每天、每 12 小时或每小时更新，缓存当前内容、左/中/右对齐和一键复制，悬浮时显示复制提示并在成功后反馈状态；关闭每日一言后改为按时间与日期类型生成默认欢迎语，也可在设置中自定义欢迎语，每日一言与任务栏歌词之间使用平滑上下转场
- **快速打开应用**：空闲页面提供快速打开区域，可从设置添加本地应用程序地址，最多添加 10 个，支持自定义名称、名称显示开关、点击启动、拖动排序和滚动查看；快速打开区域可展开/收起，并与每日一言、滴答清单今日任务及悬浮媒体卡片平滑切换；同一组应用也可从 Dock 模式的快捷应用入口直接启动
- **伴听宠物**：Dock 与沉浸模式在空闲时让伴听宠物在内容区漫游，播放时在歌词旁伴听，暂停时在旁边休息；内嵌模式的媒体悬浮卡片会在歌曲信息右侧原地伴听或休息，不会走动；完全停止、极简性能模式时不显示
- **滴答清单今日任务**：可在设置中配置[滴答清单网页版](https://dida365.com/webapp/)用户 API 口令并开启自动同步；程序启动且没有播放器会话时，会在空闲入口中显示一次今日任务概览，空闲卡片可切换到「今日任务」标签查看今天的未完成任务、截止时间和优先级标识；点击任务打开滴答清单网页中的对应详情，点击左侧复选框即可完成任务，成功后从列表移除；支持连接、立即同步和断开连接，API 口令保存于 Windows 凭据管理器，不依赖滴答清单本地客户端
- **悬浮播放控件与媒体卡片**：开启播放控件后，可选择在任务栏内嵌显示「上一首 / 播放暂停 / 下一首 / 播放模式（受支持播放器）/ 音量」（横向任务栏下可在「设置 → 媒体控件」切换「悬浮显示」或「常驻显示」在歌曲信息与歌词之间，空间较窄时自动精简按钮或回退为悬浮显示），或在任务栏外展开独立媒体卡片；媒体卡片显示播放器图标/名称、封面、歌名/歌手、当前进度、总时长、进度条与播放模式控制（受支持播放器，可在顺序播放、单曲循环与随机播放之间切换），支持纯色或磨砂玻璃背景，磨砂背景可跟随专辑主色渐变并根据背景明暗自动适配文字颜色，展开/收起和切歌均有平滑过渡，点击播放器图标或名称可打开对应音乐软件；播放中可切换到「每日一言 + 快速打开」组合面板，三类卡片共用展开方式、背景、专辑色跟随和自动适配文字颜色设置
- **应用音量独立调节**：内嵌控件新增音量按钮，悬停弹出音量滑块浮窗；媒体卡片内置音量图标与可展开滑块；通过 WASAPI 音频会话单独调节当前音乐播放器的音量（对应音量合成器中该应用的一格），不影响系统主音量，支持拖动、滚轮调节和静音
- **切歌浮窗提示**：切歌时在所选显示器中下方（可选中上方）显示圆角歌曲卡片，包含圆角方形封面、歌名和歌手两行信息；宽度按文字长度在 220～280 DIP 间调整，磨砂背景带轻微专辑色和柔和阴影，依据背后内容明暗自动适配文字颜色；弹窗固定开启鼠标穿透，点击会直接作用于下方窗口，不抢占焦点；同一显示器上连续切歌保持外框位置与宽度，内部内容淡入并重新计时；支持选择主显示器或每次弹出时鼠标所在的显示器，可设置停留时长（1~10 秒）、弹出位置，以及前台有全屏应用时不弹出；设置页提供使用当前歌曲的「预览弹窗」，需要开启弹窗、当前有歌曲且不处于极简模式
- **任务栏歌词背景**：可选择无背景、封面模糊（专辑封面高斯模糊后铺满，不透明度可调）或纯色（跟随任务栏深浅色）；背景画在最底层，可与播放进度背景、背景波浪叠加
- **播放进度背景**：从窗口左缘到歌词右缘按播放进度填充专辑主题色（无封面时回退系统强调色），不透明度可调；与频谱的背景波浪互斥
- **音频频谱**：只捕获当前音乐播放器的音频并随播放跳动，不受其他软件发声影响，支持默认、柱状图、梦幻波浪、分段电平和底缘频谱带五种样式。分段电平带有短暂停留后回落的峰值标记；底缘频谱带沿歌词区下边缘展开，不额外增加内嵌窗口宽度。梦幻波浪可作为歌曲信息和歌词背景并调节透明度；所有样式沿用跟随已播放歌词颜色、跟随专辑主题色或自定义颜色，支持颜色渐变
- **频谱特效**：在频谱样式下方独立设置柔光辉晕、衰减残影、峰值散粒和流动光泽，四项均可单独开启或组合使用，默认关闭并记忆选择。特效只作用于频谱区域；散粒跟随电平上冲触发，残影和散粒在暂停后逐渐消散，切歌或切换样式时清空历史。关闭系统动画时不播放残影、散粒和流动光泽
- **任务栏内容动态背景**：提供落叶、闪烁星星、二进制和流光粒子四种动态效果，作用范围可选仅待机内容（覆盖每日一言或欢迎语，以及资源监视区域）、仅歌词（覆盖已显示的封面、歌曲信息、歌词和频谱区域）或整个任务栏内容区域；关闭的内容区域不绘制背景，悬浮卡片不使用该效果，极简模式下关闭
- **性能模式**：在设置窗口或托盘右键菜单切换「正常 / 低渲染 / 完全停止 / 极简」；低渲染将播放动画限制在约 30 FPS 以降低 GPU/CPU 占用，完全停止会隐藏任务栏歌词、停止帧定时器并释放 GPU 资源，但保留当前会话数据，恢复后立即还原；极简模式保持正常歌词刷新率，保留基础歌词显示并将封面效果固定为方形，关闭逐字高亮、转场、频谱、附加背景、媒体卡片和切歌弹窗；低渲染、完全停止和极简模式下频谱捕获自动暂停，切回正常模式后恢复，性能模式仅对本次运行有效，重启后恢复正常；另可在「设置 → 性能」开启「全屏应用时自动切换模式」，在前台存在全屏应用时自动切换为低渲染、完全停止或极简模式，支持监测全部显示器或指定单个显示器，退出全屏后自动恢复原模式
- **动画帧率**：在「设置 → 性能」选择 30 Hz、60 Hz 或高刷新率，默认 60 Hz，选择会保存。高刷新率跟随每个任务栏窗口所在的显示器，适用于内嵌、Dock 和沉浸模式。低渲染模式固定约 30 FPS，退出后恢复保存的选择。静止时跳过重绘，隐藏时停止帧调度，部分系统合成转场按显示节奏播放
- **任务栏歌词快捷菜单**：默认可直接右键任务栏歌词打开精简菜单，快速切换显示、性能模式、内嵌模式任务栏位置、展示模式、Dock 位置、辅助歌词、切换本地/在线歌词（QQ音乐特有）或进入设置；可在「设置 → 显示」中关闭，托盘图标的完整右键菜单不受影响
- **内嵌模式多位置锚定、拖动换位与自动避让**：内嵌模式下可根据任务栏当前可用空闲区域在左侧、中间、右侧等空闲区及对应靠边锚点间选择，也可按住左键拖动整个任务栏歌词，在各个有效锚点间查看吸附预览，松手后固定并保存位置。Windows 11 下可自动避开小组件、搜索、任务视图、应用图标、TrafficMonitor 和酷狗官方任务栏歌词；空间不足时先在当前空闲区压缩，必要时迁移到更大的空闲区，所有位置都放不下时自动隐藏，并在空间恢复后自动显示。手动重新开启时可选择强制显示，但可能遮挡任务栏按钮。Windows 10 22H2 已测试基本可用，但任务栏防遮挡目前存在兼容性问题
- **外观自定义**：通用字体与界面字体独立支持配置，界面字体来源可选独立选择、跟随通用字体或系统默认；字号、粗体/斜体、歌词颜色、逐字未播放色与不透明度、光晕/描边（颜色独立可调），横向歌词支持左/中/右对齐，左右侧竖向歌词按竖排规则显示，设置持久化；字体窗口按任务栏实际尺寸、显示缩放、所选字体及歌词布局在字号列表内用浅绿色、浅黄色、浅红色背景及右侧文字，分别标注推荐字号、建议最大值和影响显示效果的字号，多显示器同时显示时采用共同适用的建议值；字体颜色与效果支持全局共用或按深色/浅色模式分别配置，已播放色可一键跟随专辑封面主色调，并支持开启底深顶浅的已播放色连续渐变
- **小任务栏适配**：按任务栏实际高度和显示缩放自动识别矮任务栏，临时停用双行歌词、星尘跟唱、逐字浮波、歌词彩蛋和辅助歌词，资源监视切换为每页两个指标的单行布局，使用滚轮依次翻页，并适配歌词、歌曲信息、资源信息、时钟字号与频谱高度。每个显示器独立适配，用户的字号和开关偏好保持不变，恢复正常尺寸后自动恢复；设置页对临时停用项显示原因
- **Fluent 风格对话框**：设置、字体选择、字体颜色与效果、颜色选择、手动搜索歌词、关于窗口以及常用提示/确认窗口统一采用 Windows 11 Fluent 风格并支持Mica材质效果；对话框支持手动调整大小并保持最小尺寸与布局比例；任务栏歌词与对话框/悬浮窗可分别跟随系统、跟随应用或固定为浅色/深色，设置页部分选项提供与实际界面对应的示意预览，高刷新率下拖动设置窗口时自动使用静态快照，减少拖动延迟
- **设置搜索与帮助入口**：点击设置窗口左上角「搜索设置」或按 `Ctrl+F`，按设置名称、选项和说明搜索，支持空格分词，点击结果或用方向键选择后回车跳转，按 `Esc` 关闭搜索；左下角固定提供文档中心、问题反馈、关于与更新入口，并显示当前版本

- **更新检查与安装**：关于窗口可选择 GitHub 或 Gitee 作为更新源，查看更新日志、下载并安装更新；开启启动时自动检查后，发现新版本会弹出提示，可直接跳转发布页或进入更新流程
- **繁简歌词匹配**：所有已适配播放器均支持繁体曲目信息匹配简体歌词。自动搜索先查原文，再尝试简体关键词，候选评分统一比较歌名、歌手和版本标注的繁简字形；手动搜索合并原文与简体查询结果，并按来源及歌曲 ID 去重。任务栏、搜索输入框和歌词保留原始文字。繁简转换使用 Windows 自带能力，地区用词与艺人别名仍需结合搜索结果判断
- **运行日志**：显示当前曲目、实际歌词来源、封面来源及预览、CPU／GPU 和专用内存。「播放与匹配」展示播放器状态、进度与歌词行、歌词格式及翻译／罗马音能力、实际匹配曲目、在线／缓存／本地获取方式、耗时和时间调整。本地 QRC 显示实际命中的索引歌名与歌手。诊断详情可展开查看 SMTC 会话标识、各来源请求次数、累计耗时和 HTTP／curl 错误码；多显示器分别显示各窗口所在屏幕的刷新率与实际提交 FPS。页面支持细滚动条和平滑滚动，日志文件按会话保存，可设置目录与清理周期
- **开机自启动**：可通过托盘菜单设置随 Windows 登录自动运行，无需管理员权限
- **歌曲信息和封面隐藏**：通过设置窗口设置隐藏歌名、歌手、专辑信息或专辑封面
- **平台识别图标**：可在专辑封面右下角显示当前播放平台图标，便于区分 QQ 音乐、网易云音乐、汽水音乐和 Spotify
- **专辑封面效果**：可在默认圆角方形封面与黑胶唱片效果之间切换；黑胶唱片在播放时旋转，暂停时保持当前位置
- **手动调整歌词进度**：对于手动搜索的歌词支持手动提前或者延迟 0.5 秒并持久化
- **未检测到播放器时的任务栏入口**：可在设置中保留或隐藏空闲入口；保留时可显示每日一言或欢迎语（默认或自定义）及快速打开应用；横向内嵌模式开启资源监视后，还可将空闲文字设为「不显示」，保留资源区；关闭空闲入口后隐藏任务栏入口

## 工作原理

- **播放状态**：通过 Windows SMTC（System Media Transport Controls）监听已适配的播放器会话。QQ 音乐按来源标识识别；网易云音乐按 InfLink-rs 写入 SMTC `Genres` 的 `NCM-{歌曲ID}` 标识识别；汽水音乐按 `SourceAppUserModelId=汽水音乐` 识别；Spotify 忽略大小写识别 `Spotify.exe`、`Spotify`，以及形如 `SpotifyAB.SpotifyMusic_<发布者标识>!Spotify` 的会话。时间线按播放器独立维护，支持播放进度插值、暂停／恢复和切歌
- **歌词来源**：已保存的手动选择优先。QQ 音乐按用户设置先匹配本地 QRC，并合并对应的翻译和罗马音。在线匹配时，网易云音乐优先按歌曲 ID 获取 YRC／LRC，汽水音乐优先匹配原生歌词并按试听片段起点对齐；未命中后依次查询酷狗 KRC、QQ 音乐 QRC／LRC、LRCLIB、网易云音乐和汽水音乐，跳过已尝试的原生来源。QQ 音乐与 Spotify 直接使用这条通用在线顺序。五个来源可跨播放器使用，LRCLIB 支持逐行 LRC 和 Lyricsfile 词级时间轴。内置 LRU 缓存避免重复请求
- **专辑封面来源**：优先使用 SMTC 原生缩略图。Spotify 原生封面缺失时先匹配 QQ 音乐专辑，仍未命中则按专辑名与专辑艺人查询 MusicBrainz，并从 Cover Art Archive 获取正面缩略图；运行日志显示实际采用的封面来源
- **滴答清单任务**：通过 Dida365 Open API 读取未关闭的任务项目，筛选当前日期范围内的未完成任务并按优先级、标题和截止信息排序；API 口令由 Windows 凭据管理器保存，任务详情通过滴答清单网页打开，完成任务时调用对应 API
- **音频频谱**：WASAPI 进程级回环捕获（`ActivateAudioInterfaceAsync`，根据当前来源捕获 QQ 音乐、网易云音乐、汽水音乐或 Spotify 的进程树，Win10 2004+ 原生支持，无驱动无注入）→ 1024 点 FFT（50% 重叠）→ 60Hz~14kHz 对数分 12 频段 →「上升立即、下降平滑」，按所选动画帧率绘制，音频采样独立运行
- **SMTC 适配结构**：QQ 音乐和网易云音乐分别处理专属时间线；汽水音乐与 Spotify 复用离散采样适配器，各实例独立维护进度状态。公共层负责会话监听、来源选择和控制转发
- **任务栏承载结构**：内嵌模式和沉浸模式使用任务栏宿主窗口；沉浸模式覆盖当前任务栏客户区，Dock 模式则切换为 Shell 管理的独立 AppBar，通过 Windows AppBar 协议协商顶部或底部工作区
- **资源监控**：Dock 模式及开启资源监视的横向内嵌模式通过独立采样线程获取系统 CPU、内存、已连接网络接口的下行/上行速率，以及可选 GPU 使用率和 CPU 当前频率；网络上下行、GPU 和频率指标可独立控制，超出一页时在资源区滚轮翻页查看；UI 只读取最近一次快照，不在绘制线程执行系统查询

## 构建

### 安装构建工具 (Windows 10/11)
- Visual Studio 2022（MSVC + Windows SDK）
- [vcpkg](https://github.com/microsoft/vcpkg)
- CMake ≥ 3.25
- Ninja (Generator)

### 使用 CMake 构建

1. 复制本机 CMake preset，并将其中的 `VCPKG_ROOT` 修改为本机 vcpkg 根目录，比如 `D:/vcpkg`
   ```powershell
   Copy-Item CMakeUserPresets.example.json CMakeUserPresets.json
   ```
2. 配置并构建 Release：
   ```powershell
   cmake --preset local-windows-msvc-release
   cmake --build --preset local-windows-msvc-release
   cmake --install build/local-windows-msvc-release --prefix dist/package --config Release
   ```
3. 如需构建 Debug：
   ```powershell
   cmake --preset local-windows-msvc-debug
   cmake --build --preset local-windows-msvc-debug
   ```

CMake 在 configure 阶段会通过 `vcpkg.json` 自动检查并安装缺失依赖，无需单独执行 `vcpkg install`。`cmake --install` 会在 `dist/package` 生成包含主程序、运行时 DLL 和许可证的完整发布目录，Inno Setup 仅负责将该目录封装为安装包。首次切换 preset 或 toolchain 时，可在 configure 命令中添加 `--fresh` 以清除旧的 CMake cache。

## CI/CD 与发布

GitHub Actions 仅在推送 `v*` 版本标签时执行 Windows x64 Release 构建、测试和发布构建校验，生成安装包并发布 GitHub Release。普通分支推送和 Pull Request 不触发软件构建，也不提供手动构建入口。构建产物可在对应的 Actions 运行记录中下载；网站仍由独立的 Pages 工作流部署。

Release 正文来自仓库中的 `.github/release-notes.md`。每次发版前，将更新说明写入该文件并随版本修改一起提交，再推送对应标签。Actions 会将文件中的 Markdown 原文用作 Release 内容，不再自动生成默认发布说明。应用内关于页的更新日志也读取同一份 Release 内容。

创建 GitHub Release 时，先同步修改 `src/app_info.h` 与 `installer/WindowsTaskbarLyrics.iss` 中的版本号，然后推送同版本标签，例如：

```powershell
git tag v2.7.0
git push origin v2.7.0
```

标签中的核心版本必须与源码版本一致。带后缀的标签（例如 `v2.7.0-fork.1`）会自动发布为 prerelease，适合在 fork 仓库验证；不带后缀的标签会发布为正式版本。

## 使用

完整操作说明与选项限制见[文档中心](https://www.taskbar-lyrics.top/docs.html)。

1. 运行 `WindowsTaskbarLyrics.exe`，再打开 QQ 音乐、网易云音乐、汽水音乐或 Spotify 播放歌曲，歌词会自动出现在任务栏上
2. 右键托盘图标：
   - **开启/关闭任务栏歌词**：显示或隐藏任务栏歌词
   - **性能模式**：直接切换正常 / 低渲染 / 完全停止 / 极简模式；完全停止时如需显示任务栏歌词，请先切换到其他模式
   - **任务栏位置**：内嵌模式下动态列出当前任务栏的可用空闲区域及停靠位置（如左侧、中间、右侧空白区及靠左／靠右、靠上／靠下锚点，适配开始菜单居中等多段空闲布局）；也可直接拖动任务栏歌词切换锚点
   - **展示模式**：切换内嵌 / 沉浸 / Dock 模式；沉浸模式需要横向任务栏和活动音乐会话
   - **Dock 位置**：Dock 模式下可选屏幕顶部或底部，并通过 AppBar 为桌面工作区预留空间
   - **手动搜索歌词**：自动匹配不准时手动选词，支持手动提前或者延迟0.5秒并持久化
   - **切换歌词版本**：启用 QQ 音乐本地歌词并命中歌词后，可在本地版与在线版之间切换；在设置中开启「切换版本持久化」后会按歌曲记住选择
   - **辅助歌词**：当前歌曲有可用翻译或罗马音时，可直接切换翻译、罗马音或关闭显示辅助歌词
   - **设置…**：打开设置窗口，集中调整显示、性能、悬浮卡片、悬浮媒体控件、频谱、歌词、切歌弹窗及每日一言与应用速启
   - **开机自启动**：登录 Windows 时自动运行（写入 HKCU Run 注册表项）
   - **检查更新…**：菜单右侧显示当前版本号；点击打开关于窗口，选择 GitHub/Gitee 更新源、查看更新日志、检查并安装 Release 更新，以及设置启动时自动检查；检测到新版本时会弹出更新提示
   - **运行日志**：查看当前播放、歌词来源、封面加载和资源占用状态，可切换预览已加载的封面图片，打开日志目录或设置日志保留周期
   - **重启应用**：正常退出当前进程后重新启动，保留已保存的设置；性能模式按启动规则恢复为正常
   - **退出**：退出程序
3. 在 **设置…** 窗口中：
   - **搜索与帮助**：点击左上角「搜索设置」或按 `Ctrl+F` 搜索并跳转设置项；左下角可打开文档中心、问题反馈和关于与更新，并查看当前版本
   - **显示**：设置任务栏内容与对话框/悬浮窗的系统、应用、浅色或深色主题，选择通用字体，设置界面字体来源（独立选择 / 跟随通用字体 / 默认）与自定义界面字体，显示/隐藏歌曲信息、专辑封面和平台图标，开启/关闭任务栏歌词右键快捷菜单，选择默认或黑胶封面效果，选择任务栏内容背景（无 / 封面模糊 / 纯色）并调节封面模糊不透明度，开启播放进度背景并调节其不透明度，选择任务栏动态背景效果及其作用范围，部分选项可直接查看示意预览
   - **展示模式**：选择内嵌 / 沉浸 / Dock 展示模式、目标显示器及 Dock 顶部 / 底部位置（内嵌固定显示在主显示器，展开模式可选单台或全部显示器），分别调节沉浸与 Dock 遮罩不透明度（或模糊程度）；开启内嵌资源监视，独立控制网络下行、网络上行、GPU 使用率和 CPU 频率指标
   - **性能**：选择正常 / 低渲染 / 完全停止 / 极简，以及 30 Hz / 60 Hz / 高刷新率。动画帧率默认 60 Hz 并保存，性能模式仅对本次运行有效；极简模式保留基础歌词，关闭逐字高亮、转场、频谱、附加背景、媒体卡片和切歌弹窗；支持开启「全屏应用时自动切换模式」，设置「目标显示器」（全部显示器或指定显示器）及「全屏时目标模式」（低渲染 / 完全停止 / 极简），退出全屏后自动恢复原模式
   - **悬浮卡片**：设置媒体卡片、每日一言和快速打开卡片的展开方式（悬浮 / 点击）、背景（纯色 / 磨砂玻璃）、背景颜色预览、磨砂背景跟随专辑主色和自动适配文字颜色
   - **媒体控件**：设置是否显示播放控件、控件样式（内嵌控件 / 媒体卡片），以及内嵌控件的显示方式（悬浮显示 / 常驻显示；常驻显示仅用于横向非极简回退布局）；只有支持的播放器才会显示播放模式控制按钮
   - **频谱**：开启/关闭频谱，在五种样式卡片中选择默认、柱状图、梦幻波浪、分段电平或底缘频谱带；下方「频谱特效」可独立开关柔光辉晕、衰减残影、峰值散粒和流动光泽。频谱颜色支持跟随已播放歌词颜色、跟随专辑主题色和自定义颜色，可以开启颜色渐变；梦幻波浪可作为歌曲信息和歌词背景，并调节背景不透明度（与播放进度背景互斥）
   - **歌词**：开启双行歌词，选择左对齐/居中/右对齐，设置歌词字体颜色与效果，设置已播放颜色是否跟随专辑，开启/关闭歌词已播放色渐变，独立开关六项歌词特效（星尘跟唱、跟唱流光、笔触下划线、字间涟漪、逐字浮波、歌词彩蛋），开启翻译/罗马音并切换辅助歌词类型；启用 QQ 音乐本地歌词、选择本地歌词目录并设置切换版本持久化
   - **切歌弹窗**：设置开关、停留时长、中上／中下位置、主显示器／当前鼠标所在显示器和前台全屏应用时是否弹出；开启弹窗且当前有歌曲时，可点击「预览弹窗」查看效果，极简模式下不可用
   - **每日一言与更多**：设置是否保留未检测到音乐播放器会话时的任务栏入口，空闲文字可选每日一言、欢迎语或不显示（新选择不显示需要横向内嵌模式已开启资源监视）；设置每日一言来源（一言 / 今日诗词）、更新频率和对齐方式，编辑自定义欢迎语；在快速打开区域添加本地 EXE、编辑名称、显示/隐藏名称、拖动排序或删除应用，最多 10 个
   - **滴答清单**：在设置中填写 [滴答清单网页版](https://dida365.com/webapp/)「设置 → 账号与安全 → API 口令」创建的普通用户 API 口令，然后开启自动同步；可使用「连接滴答清单」「立即同步」和「断开连接」管理任务数据，断开连接会删除本机保存的 API 口令
4. 直接操作任务栏歌词：
   - **点击专辑封面**：打开当前歌曲对应的音乐应用，无需先展开媒体卡片
   - **右键**：打开精简快捷菜单；可在「设置 → 显示」中关闭此功能，托盘图标右键菜单不受影响
   - **左键拖动**：拖动时显示锚点吸附预览，松手后固定到更接近的有效锚点并保存位置；未超过系统拖动阈值时仍按原有点击操作处理
5. 开启播放控件并选择「内嵌控件」时，可选择鼠标悬浮歌词区域显示播放控制按钮，或设置为常驻显示在歌曲信息与歌词之间（可在设置中选择关闭，默认开启；当前播放器支持时还会显示播放模式按钮，可在顺序播放、单曲循环与随机播放之间切换）；选择「媒体卡片」时会展开独立卡片（可选悬浮或点击展开），显示播放器和歌曲播放进度，点击卡片顶部的播放器图标或名称可打开对应音乐软件，播放中还可切换到「每日一言 + 快速打开」组合面板；无播放时可在「快速启动」与「今日任务」标签间切换，点击任务行打开滴答清单网页详情，点击左侧复选框完成任务；每日一言、快速启动与今日任务的展开、收起和切换均有平滑过渡；在每日一言页点击复制按钮可复制内容，快速打开区域可通过箭头展开或收起；悬浮内嵌控件的音量按钮或媒体卡片的音量图标，可拖动滑块单独调节音乐应用音量，不影响系统主音量
6. 在「沉浸」或「Dock 模式」中，固定操作区提供上一首、播放/暂停、下一首、播放模式（受支持播放器）、音量、返回内嵌和完整菜单；鼠标停在这些控件以外的区域时沉浸条会淡出、露出原任务栏供操作，鼠标离开任务栏后再淡入恢复；Dock 模式会显示 CPU、内存及已开启的扩展指标，并提供快捷应用入口，资源指标超出一页时可用鼠标滚轮翻看；两种模式在空闲、播放和暂停时都会分别显示漫游、伴听和休息状态的宠物。返回内嵌不会退出程序，完全退出请使用菜单中的「退出」

> QQ 音乐桌面版（`QQMusic.exe`）需要在 QQ 音乐设置中打开“显示系统媒体传输控件（SMTC）”；网易云音乐桌面版需要先按下方说明安装 BetterNCM 和 InfLink-rs；汽水音乐和 Spotify 使用客户端原生 SMTC。仅支持 64 位 Windows；Windows 10 22H2 已测试，除任务栏防遮挡外其余核心功能基本正常（频谱功能需 Windows 10 2004 及以上）。

### 竖向模式限制

当 Windows 任务栏位于左侧或右侧时，程序会自动进入竖向模式。为保证窄栏中的内容可读，以下设置会在设置窗口中禁用，竖向期间无法开启或切换：

- **显示歌曲信息**：固定关闭
- **内嵌显示方式**：固定为「悬浮显示」，不可切换为「常驻显示」
- **双行歌词**：固定关闭
- **歌词对齐**：由竖排布局接管，横向的左对齐 / 居中 / 右对齐选项不可切换
- **逐字浮波**：竖向任务栏下不可用
- **翻译/罗马音**：辅助歌词总开关固定关闭，「翻译 / 罗马音」类型不可切换
- **内嵌资源监视**：竖向任务栏下不可开启；Dock 为独立横栏，不受任务栏方向影响
- **频谱相关设置**：竖向期间频谱暂停并禁用总开关、配色、样式、特效及背景波浪设置，保留原有配置偏好
- **每日一言字体对齐方式**：固定为左对齐，左对齐 / 居中 / 右对齐选项不可切换

播放进度背景不属于频谱功能，竖向模式下仍可单独开启。切回横向任务栏后，歌曲信息、内嵌显示方式、双行歌词、歌词对齐、逐字浮波、歌词彩蛋、辅助歌词、资源监视和频谱相关设置会按保留的偏好恢复可用。

## 网易云音乐适配

网易云音乐桌面版需要额外的 SMTC 增强插件才能提供歌曲 ID 和可靠的播放进度。使用网易云音乐前必须安装 BetterNCM 和 InfLink-rs：

1. 从 [BetterNCM Installer](https://github.com/std-microblock/BetterNCM-Installer/releases/latest) 下载并安装 BetterNCM。
2. 打开网易云音乐的 BetterNCM 插件商店，搜索并安装 **InfLink-rs**。
   > 如果插件商店不可用，也可以从 [InfLink-rs Releases](https://github.com/apoint123/inflink-rs/releases/latest) 下载插件后手动安装。
3. 按提示重启网易云音乐，再运行或重启 `WindowsTaskbarLyrics.exe`。

> 只安装 **InfLink-rs**，不要同时安装旧版 InfLink。网易云适配的可用性受 BetterNCM、InfLink-rs 以及网易云音乐客户端版本影响，不保证所有版本均可用。

### UI Automation 注意事项

Windows 10 22H2 的任务栏 UI Automation 树与 Windows 11 不完全一致。程序的任务栏防遮挡会在后台通过 `TaskbarFrame` 的 UI Automation 子树读取开始、搜索、任务视图和应用按钮的矩形；在 Windows 10 上可能无法完整读取这些元素，因此自动避让可能漏掉搜索或应用图标等占用区，出现歌词与任务栏按钮重叠、压缩或自动隐藏不符合预期的情况。

该限制主要影响任务栏防遮挡；沉浸模式的歌词、播放控件、完整托盘菜单与让出任务栏交互，以及 Dock 模式的 Windows AppBar 工作区不使用这条 UI Automation 查找链。

## 常见问题

### 播放歌曲后为什么没有显示歌词？

先确认托盘菜单中的任务栏歌词处于开启状态，性能模式不是「完全停止」。QQ 音乐需要在自身设置中开启「显示系统媒体传输控件（SMTC）」；网易云音乐需要正确安装 BetterNCM 与 InfLink-rs。如果任务栏没有足够的安全空间，歌词会自动隐藏，并在空间恢复后重新显示。

### 为什么网易云音乐必须安装额外插件？

网易云音乐官方软件提供的SMTC信息没有进度显示，为了保证完整的使用体验，网易云音乐桌面版需要 InfLink-rs 补充歌曲 ID 和可靠的播放进度，程序才能匹配歌词并保持时间轴同步。安装步骤见[网易云音乐适配](#网易云音乐适配)。

### 为什么频谱没有显示？

频谱只捕获当前音乐播放器进程的音频，并要求 Windows 10 2004 或更高版本。请确认播放器正在发声、频谱已在设置中开启，并切换到「正常」性能模式；低渲染、完全停止和极简模式会暂停频谱捕获，竖向任务栏模式也会关闭频谱。
